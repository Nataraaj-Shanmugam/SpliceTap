SpliceTap Browser Extension

Mock any API in 30 seconds, directly in your browser

📦 Installation Instructions

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top right corner
  3. Click "Load unpacked" and select the SpliceTap extension directory
  4. The SpliceTap icon should appear in your toolbar
  5. Start mocking APIs instantly!

🚀 Quick API Mocking

Create mock responses for any API endpoint in seconds. Support for all HTTP methods and custom headers.

🎯 Pattern Matching

Use wildcards, regex patterns, or exact URLs to match requests. Flexible and powerful matching system.

🧪 Built-in Testing

Validate your mock rules with comprehensive testing. Check patterns, JSON syntax, and response codes.

🌙 Dark/Light Theme

Beautiful interface with automatic theme detection or manual selection. Designed for developer productivity.

📤 Import/Export

Backup and share your mock rules. Export to JSON format and import from other developers.

⚡ High Performance

Fast request matching with minimal CPU usage. Optimized for development workflows.
